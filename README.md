# Gestor de Contraseñas

## Descripción del proyecto

Aplicación de consola desarrollada en C# para gestionar contraseñas. Permite agregar, visualizar, actualizar y eliminar registros, almacenando la información en una base de datos SQLite.

## Tecnologías utilizadas

- C#
- .NET
- Entity Framework Core
- SQLite
- Spectre.Console

## Instrucciones para ejecutar

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir una terminal dentro de la carpeta del proyecto.
3. Ejecutar:

```bash
dotnet run
